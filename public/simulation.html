How it was run

  1. Three hospitals with the same demand profile as the demo. One over-orders for its usage, one runs lean.
  2. Each morning, sites order up to a par level of their own demand. Units arrive with 3 to 4 days of shelf life. Sites don't stock AB platelets.
  3. Demand per blood group is random (Poisson). Both policies see exactly the same demand and deliveries, so differences come from the rule alone.
  4. Patients get platelets in the order set by the SNBTS Policy for Platelet Selection: identical group first, then compatible groups. Group O never goes to non-O patients, and RhD-positive never goes to RhD-negative patients.
  5. With the rule, the same engine the live app uses runs every morning and moves units projected to expire unused to a site that will use them.
  6. Each run has a 5-day warm-up, then 30 counted days. Results are averaged over 20 runs.
